# 목표

새로 mason-report를 접하거나 리포트의 표기(예: ✅/🔶/❔)가 헷갈리는
사용자에게, 플러그인 사용법과 리포트 표기 기준을 그 자리에서 설명한다. 이 명령은 로그를
조회하거나 분석하지 않는다 — 순수하게 사용 안내 문서를 출력하는 정적 명령이다.

# 절차

아래 "출력 형식"은 한국어로 작성된 참고본(reference)이다. **사용자가 지금 이 대화에서
쓰고 있는 언어로** 같은 구조·같은 내용을 다시 작성해서 출력한다 — 이는 Claude가 평소
사용자 언어에 맞춰 응답하는 것과 동일한 기준이며, 사용자가 한국어로 대화 중이면 참고본을
그대로 사용해도 된다. 언어를 임의로 추측하기 위해 OS 로케일이나 국가 정보를 조회하지
않는다 — 이 대화에서 사용자가 실제로 쓰고 있는 언어를 그대로 따른다. 로그 조회나 계산이
필요 없으므로 Tool을 호출하지 않는다. 번역 시에도
`plugins/mason-report/skills/decision-analysis/SKILL.md`의 정의와 어긋나지 않게 유지한다 —
이 명령의 설명 내용이 그 Skill의 등급 기준을 요약한 것이기 때문이다.

# 출력 형식

아래 "출력 형식"은 **존댓말·짧은 단락**으로 쓴 참고본이다 — 문장을 길게 늘어뜨리지 않고,
한 단락에는 핵심 하나만 담는다. 세부 근거(예: 왜 % 수치를 쓰지 않는지)는
`SKILL.md` 쪽이 이미 상세히 다루므로, 이 안내에서는 결론만 짧게 전달하고 필요하면
`SKILL.md`로 안내한다.

```markdown
# Mason Report 사용법

mason-report는 Claude Code가 요청을 어떻게 처리했는지, **실제로 관찰된 증거만**으로
재구성해서 보여드리는 로컬 도구입니다.

Claude의 비공개 생각 과정은 들여다보지 않습니다. 어디로도 전송하지 않고, 로컬에만
남습니다.

## 명령어

| 명령어 | 하는 일 |
|---|---|
| `/mason-report:latest [n]` | 최근 완료된 턴을 자동으로 골라 분석합니다 (기본 1턴) |
| `/mason-report:select [n]` | 원하는 턴을 직접 골라 분석합니다 |
| `/mason-report:all` | 현재 세션 전체를 턴 단위로 요약합니다 |
| `/mason-report:status` | 로그가 잘 쌓이고 있는지 확인합니다 |
| `/mason-report:readme` | 지금 보고 계신 이 사용법 안내입니다 |

## 리포트 구성

턴 하나를 분석하는 리포트(`/mason-report:latest`, `/mason-report:select`)는 위에서부터
이렇게 읽으시면 됩니다.

1. **요약**: 맨 위 한두 문장입니다. 여기만 읽어도 결과를 알 수 있습니다.
2. **요청**: 분석 대상 프롬프트 원문입니다.
3. **실제로 한 일**: 도구 호출을 "조사 → 수정 → 검증 → 커밋"처럼 단계로 묶은 표와,
   소요 시간·호출 횟수·토큰을 담은 한 줄입니다.
4. **요청 문구별 해석**: 프롬프트의 각 문구가 어떤 행동으로 이어졌는지 보여주는 표입니다.
5. **최종 답변 검증**: Claude의 답변이 로그와 맞는지 확인한 결과입니다.
6. **원본 로그**: 실제 기록된 이벤트 전체입니다. 접혀 있으니 필요할 때만 펼쳐 보세요.

## 표기

| 표기 | 뜻 |
|---|---|
| ✅ | 로그로 확인된 사실입니다 |
| 🔶 | 관찰된 행동으로 미루어 짐작한 해석입니다 |
| ❔ | 로그만으로는 알 수 없습니다 |
| ❌ | 도구 호출이 실패했습니다 |
| ⚠️ | 답변이 로그와 어긋나거나, 요청과 다르게 처리된 점입니다 |

❔는 "관여하지 않았다"가 아니라 "판단할 근거가 없다"는 뜻입니다.

## % 수치를 쓰지 않는 이유

Claude 내부의 판단 확률은 Hook에 기록되지 않습니다. 그래서 %를 적으면 실제 측정값처럼
오해되기 쉬워, 판정은 ✅/🔶/❔로만 표시합니다.

## 토큰 사용량

**이미 끝난 턴**에 한해 실제 토큰 사용량을 "실제로 한 일" 아래 한 줄에 보여드립니다.
추정이 아니라 API에 실제로 찍힌 수치를 더한 값입니다(✅). Subagent를 사용했다면 따로
표시합니다.

아직 진행 중인 턴이나, 이 기능이 생기기 전에 기록된 옛 로그는 ❔로 남겨둡니다.

## 더 자세한 기준

더 정확한 판정 기준은 `plugins/mason-report/skills/decision-analysis/SKILL.md`에
있습니다. 이 안내와 다르게 보이면 그쪽이 최신 기준입니다.
```
